# 훈령 도식 검수 기록

검수일: **2026-11-27 (한국시간)**

## 제80회 기존 스크립트 기준 보정

2026-11-27 사용자 정정에 따라 기존 통합 강의 스크립트 78편을 내용 기준으로 고정했습니다. 원고 파일 78편의 경로·Git blob·SHA-256을 검증해 연결했습니다. DR-036-D01·DR-041-D01은 원고의 시험 표현인 “수령과 동시에”로 부제를 맞추고, DR-060-D06은 제80회 적용 내용에 맞게 “시행 예정”을 제거했습니다. 세 장의 SVG·PNG·WebP를 다시 생성했으며 영역·겹침 오류 0건, PNG/WebP 픽셀 일치를 확인했습니다.

이는 스크립트 78편 전체의 상세 도식 대조가 완료됐다는 뜻이 아닙니다. [보정 검수 기록](script-alignment-qa.json)과 [작업 큐](production-queue.json)에서 남은 대조를 관리합니다. 아래 검수 결과는 최초 제작 당시 기록입니다.

## 최초 제작 결과

**78강 / 190장 / SVG·PNG·WebP 각 190개.** 현재 무한회독 강의 목록 DR-001~DR-078의 모든 강의에 도식이 있습니다. 도식은 해당 강의의 핵심 사항을 요약하며, 법령의 모든 문장을 그대로 수록한 전재본은 아닙니다.

| 검수 항목 | 결과 |
|---|---|
| 강의 누락·중복 ID | 78개 강의 모두 포함, 도식 ID 중복 없음 |
| 조문과 강의 번호 매칭 | 실제 강의 목록과 대조 |
| 공식 조문 대조 | 조직·편성 제3104호 / 교육훈련 제3216호 |
| 독립 내용 검토 | 190장 전부 2차 검토, 지적 19건 보완 |
| 원문 증거 | 공식 조문·공식 별표에서 확인한 근거 기록 |
| 글자 겹침·출력 영역 이탈 | 190장 전체 검사 0건 |
| 본문 글자 크기 | 35~36px / 1600×1120 기준 |
| 서체 문자 지원 | 사용 문자 누락 0개 |
| PNG·WebP 해상도 | 전부 1600×1120 |
| 육안 검토 | 비교·절차·목록·긴 용어·시행일 주석을 포함한 대표 도식 확인 |
| 파일 무결성 | 전체 파일의 바이트 수·SHA-256을 매니페스트에 기록 |

## 내용 검토에서 보완한 사항

조직·편성 도식에서는 중대 이상 지휘관의 적용 범위, 지역예비군대원 선발 조건, 시·군·자치구 내 인접지역 확산 범위, 수임군부대장의 위임·위탁, 초과무기의 판단기준, 부대 단위 저장 원칙, 거주불명자의 고발 시기 표현을 보완했습니다.

교육훈련 도식에서는 인터넷 신청 적용대상, 직접교육 지휘관 요건, 지원예비군 훈련 용어, 특전예비군의 작계·입영 불참 처리 구분, 참가비 정의, 원격교육 출처, 귀국자 보류해소 기산점, 기존 보류자의 휴직 조건, 호송단의 역할, 지연도착 시 보충훈련, 일정조정 승인항목, 정당한 사유에 의한 조퇴 예외를 보완했습니다.

DR-045를 존재하지 않는 제2조의2, DR-047을 존재하지 않는 제3조의3으로 표기하지 않았습니다.

## 시행일 구분

교육훈련 훈령 제3216호는 2026-10-14 시행이며, **제16조제4항제4호는 2027-01-01 시행**입니다. 5~6년차 병 상비예비군의 훈련 전환을 설명하는 DR-060 도식에 이 시행일을 별도로 표시했습니다.

## 디자인과 출력

사용자가 선택한 `07-notion-editorial.svg`를 기준으로 종이색 배경 `#FFFEFC`, 검은 글자 `#25241F`, 얇은 구분선, 왼쪽 손괄호와 오른쪽 동그라미를 적용했습니다. 어절 단위로 줄바꿈하며, 긴 고유명사 때문에 열 폭이 부족하면 두 열의 폭을 조정합니다. 글자를 자르거나 말줄임표로 바꾸지 않습니다.

WebP는 무손실 압축이며 PNG와 동일한 화면을 제공합니다. SVG는 편집 가능한 원본으로, Noto Sans CJK KR 서체가 설치된 환경에서 같은 형태로 표시됩니다.
