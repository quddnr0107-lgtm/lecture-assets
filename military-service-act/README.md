# 제80회 병역법 강의 도식

**현재 파일: MS-001~MS-166 · 핵심 도식 292개 · 이미지 316장**

**내용 기준은 제80회(27년 전반기) 기존 강의 스크립트입니다.** 원고의 설명·숫자·조건·예시를 도식으로 정리합니다. 현재 166편 원고의 파일·경로·해시를 확인했고, 도식과의 내용 대조를 진행합니다.

사용자가 선택한 흑백 편집형 디자인을 기준으로 제작했습니다. 넓은 여백, 굵은 제목, 얇은 구분선, 문서 선화, 손그림 밑줄·타원·괄호를 사용합니다.

## 파일 사용

`lesson-NNN/diagrams/MS-NNN-DNN-editorial-v1.webp`는 1600×1120 무손실 강의용 이미지입니다. 동일한 이름의 `.svg`는 편집 원본입니다. 각 강의 폴더의 `manifest.json`에 실제 강의 ID, 도식 순서, 근거 조문, 공식 원문 URL, 파일 크기와 SHA-256이 들어 있습니다.

가로세로 비율을 유지하여 표시하고, 잘라내지 않는 `object-fit: contain`을 사용합니다. 작은 화면에서는 확대 또는 단독 표시가 적합합니다. 원본 SVG의 글꼴은 Noto Sans CJK KR이며, WebP에는 글자가 완전히 렌더링되어 있습니다.

## 내용 기준과 현재 검수 상태

기존 제80회 원고는 비공개 원본 저장소의 `docs/merged-lectures/병역법/`에 있습니다. [원고 목록](script-sources-exam80.json)에 166강 각각의 정확한 경로와 파일 해시를 기록했습니다. 제80회·27년 전반기 설정을 확인했으며 기존 학습 기준일 2027-02-02는 유지합니다.

현재 **기존 23장은 원고 근거 대조를 마쳤고, 나머지 260장은 대조 대기**입니다. 전체 핵심 설명 검토 완료는 17강이며, 신규 보완 33장을 공개했습니다. 도식 문장 근거 확인만 된 강의는 전체 설명 검토 완료로 세지 않습니다. [대조 기록](script-alignment-audit-exam80.json)을 확인할 수 있습니다.

원고에 있는 학습 내용을 기준으로 기존 도식을 활용하고, 실제로 어긋난 내용이나 필요한 보완만 수정·제작합니다. 기존 조문 목록에서 만든303건 생산 계획은 철회해 이력으로 보존하고, **166강의 실제 원고를 읽고 대조하는 작업**으로 바꿨습니다. 외부 조문만으로 원고 밖 내용을 추가하거나 강의 원고를 다시 쓰지 않습니다.

초기 제작에 사용한 법령 참고 정보와 배치 검수는 [기존 제작 기록](editorial-audit.json)에 보존합니다. 현재의 제작 범위는 기존 스크립트가 정합니다.

## 내용 수정 후 재생성

필요 도구: Python 3 + Pillow + Noto Sans CJK 폰트, Node.js + sharp.

```sh
python military-service-act/tools/build_editorial.py
node military-service-act/tools/render_editorial.cjs
```

선택적으로 `--png`를 주면 검수용 PNG도 생성할 수 있습니다. 변경 뒤에는 내용·출처, 경계 검사, 렌더링 화면, 강의별 목록과 해시를 다시 확인합니다. 기존 사진 자산은 같은 강의 폴더에 유지됩니다.
