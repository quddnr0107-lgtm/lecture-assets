# 훈령 강의 도식

**78강 전체 · 234장**. 무한회독 강의용 도식입니다. 사용자가 선택한 흰 종이 바탕, 검은 글자, 얇은 구분선, 손으로 그은 괄호와 동그라미 디자인을 적용했습니다.

## 파일 형식

| 형식 | 용도 | 전체 용량 |
|---|---|---:|
| WEBP | 사이트·강의 화면 삽입 / 무손실 압축 | 10.24 MiB |
| PNG | 영상 편집·발표 자료 삽입 | 33.64 MiB |
| SVG | 확대·문구 편집용 벡터 원본 | 1.30 MiB |

모든 도식은 1600 × 1120 비율입니다. SVG의 지정 서체는 Noto Sans CJK KR이며, PNG·WebP에는 글자가 이미지로 고정되어 있습니다.

## 내용 기준: 제80회 기존 강의 스크립트

도식의 내용·순서·강의 번호는 **제80회(2027년 전반기) 기존 통합 강의 스크립트 78편**을 기준으로 합니다. [스크립트 기준](diagrams/SCRIPT-BASIS.md)과 [강의별 경로·해시](diagrams/script-basis.json)를 연결했습니다. 기존 190장의 파일 제작은 완료됐으며 전체 스크립트와의 일치·필요 보강 검토는 작업 큐에서 진행합니다.

다음 공식 원문은 인용 확인에 사용하는 보조 근거입니다.
- [예비군 조직·편성과 운영에 관한 훈령](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000268674): 국방부훈령 제3104호, 시행 2025-11-14
- [예비군 교육훈련 훈령](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000286712): 국방부훈령 제3216호, 시행 2026-10-14

교육훈련 제16조제4항제4호는 **2027-01-01 시행**이며 제80회 기존 스크립트의 적용 내용으로 표시합니다. 저장소의 제80회 기준일은 2027-02-02입니다.

최근 검수: 제80회 원고 상세 대조 46/78강, 도식 226장 제작·검수. DR-064·DR-065·DR-072 수정 6장 실제 WebP 대조, 18개 파일 SHA-256 및 해상도 확인 완료 (2026-11-28).
