# 예비군법 제80회 스크립트 도식 작성 기준

## 내용 기준

- 내용은 `quddnr0107-lgtm/yebijun-muhanhoidok234`의 `docs/merged-lectures/예비군법/*.txt` 기존 34강 스크립트만 따른다.
- 강의 번호는 `_deploy/integrated-lectures-catalog.json`의 `RL-001`~`RL-034`와 고정 연결한다. 출처 커밋과 해시는 `source-index.json`에 기록한다.
- 외부 법령으로 원고를 재구성하지 않는다. 원고에서 확정할 수 없는 내용은 별도 검토 항목으로 남긴다.
- 각 강의의 설명 순서를 지키며 주체·대상·권한·절차·기한·숫자·원칙·예외를 구분한다. 회상 질문이나 오답을 정답처럼 그리지 않는다.
- 한 장에 한 관계만 설명한다. 내용이 많은 강의는 여러 장으로 나누며, 특히 RL-004의 다섯 줄기를 모두 다룬다.
- 비유·일화·자기소개를 억지로 도식화하지 않는다. 원문에서 다룬 중요한 시험 구별점과 조건을 보존한다.

## 편집 가능한 콘텐츠 형식

`content/RL-NNN.json`은 다음 구조를 사용한다. `source`는 자동으로 source-index에서 결합한다.

```json
{
  "lessonId": "RL-001",
  "lessonTitle": "예비군법 제1조, 목적",
  "diagrams": [
    {
      "id": "purpose-scope",
      "title": "법이 정한 네 가지 사항",
      "subtitle": "국가를 방위하기 위한 설치·조직·편성·동원",
      "kind": "compare",
      "left": {
        "title": "제도와 부대 구성",
        "items": [
          {"label": "설치", "text": "예비군이라는 조직을 둠"},
          {"label": "조직·편성", "text": "부대를 짜고 사람을 배치함"}
        ]
      },
      "right": {
        "title": "필요할 때 소집",
        "items": [{"label": "동원", "text": "필요한 때 예비군을 불러 모음"}]
      },
      "note": "제1조의 네 번째 낱말은 동원",
      "sourceRanges": [{"startLine": 17, "endLine": 35, "topic": "목적의 네 낱말"}]
    }
  ],
  "coverage": [{"topic": "핵심 설명 갈래", "diagramIds": ["purpose-scope"]}],
  "review": {
    "scriptReadInFull": true,
    "scope": "script-only",
    "checked": ["주체", "대상", "기한", "예외", "설명 순서"],
    "issues": []
  }
}
```

- `kind`는 `compare`, `process`, `rule`, `deadline`, `exception` 중에서 고른다. 모두 같은 2열 카드 규격으로 그리며 `process`에 한해 순서 표지를 사용한다.
- `title`은 가급적 22자 이내, 열 제목은 가급적 16자 이내로 쓴다. 의미를 훼손하는 축약은 하지 않는다.
- 각 열은 1~3개 항목, 항목 `label`은 15자 안팎, `text`는 65자 이내를 권장한다. 초과하면 다른 장으로 나누어 큰 글자를 유지한다.
- `note`는 한 문장으로 원칙·예외·구별점을 적는다. 대략 55자 이내. 원고에 없는 숫자·조건·효과를 추가하지 않는다.
- 각 장의 `sourceRanges`는 실제 원고의 1부터 시작하는 줄번호이며, 장의 모든 법적 명제를 뒷받침하는 구간을 적는다. 여러 구간을 기재할 수 있다.
- 도식당 하나의 출처 줄 범위로 강의 전체를 통째로 지정하는 방식은 피한다. 주제별 구간을 구체적으로 잡는다.
- `coverage`는 원고의 실제 주요 줄기를 빠짐없이 나열하고 관련 도식 ID를 연결한다.
- 전체 원고를 공개 저장소에 복사하지 않는다. 공개 콘텐츠에는 필요한 요약과 출처 경로·해시·줄번호만 둔다.

## 시각 기준

- 기존 공통 제작 기준 v9에 따라 16:9, 배경 `#F4F4F4`, 흰 카드, 본문 `#202124`, 보조 `#545860`, 강조 `#275AA3`를 사용한다.
- Noto Sans CJK KR, 본문 32px 이상(1600px 폭 기준), 고정 글꼴 크기. 글자를 줄여 끼워 넣거나 말줄임하지 않는다.
- 어절·조사·숫자와 단위·조문 표기를 붙여 줄바꿈한다. 폭이 모자라면 내용 단위별로 장을 나눈다.
- '또는'과 병렬 선택은 동급 관계로 표시한다. 지휘나 승인 관계를 뜻하지 않는 화살표는 쓰지 않는다.
- 모든 SVG를 PNG로 렌더링하고 경계 넘침·겹침·한글·원본 연결·갤러리 링크를 확인한다. 자동 검사와 직접 읽은 내용 검수를 구분한다.
