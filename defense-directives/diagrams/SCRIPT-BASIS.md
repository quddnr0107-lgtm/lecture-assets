## 제작 규칙

1. 원고의 내용·설명 순서·수치·주체·조건·예외·시험 핵심 표현을 그대로 시각화한다.
2. 사용자가 선택한 흑백 편집형 디자인을 유지하고 필요한 도식을 강의 번호별로 정리한다.
3. 기존 원고·음성·영상은 변경하지 않는다. 공개 저장소에는 강의 원고 전체를 복사하지 않는다.
4. 공식 법령은 인용 확인용 보조 근거로 사용한다. 오늘 기준 현행 법령으로 강의 원고를 따로 만들지 않는다.
5. 원고가 바뀌면 해당 강의의 실제 변경 구간과 해시를 확인해 필요한 도식만 다시 처리한다.
