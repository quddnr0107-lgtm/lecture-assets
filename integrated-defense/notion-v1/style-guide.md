## 내용과 구조

내용 기준은 **제80회(27년 전반기) 기존 통합방위법 스크립트**다. 기존 원고의 기관명·숫자·요건·예외·설명 순서를 보존하며 원고 밖 최신법 설명을 추가하지 않는다. [기준 원고·해시](../production-queue/EXAM80-SCRIPT-SOURCE.json), [55개 원고 일치 검수](script-alignment.json)를 확인한다.

- 절차·논리 관계를 나타낼 때만 순서 화살표를 사용한다. 목적 조문의 논리 구조는 시간 순서와 구분한다.
- 비교·구성·권한의 병렬 관계는 독립 열과 괄호로 나타낸다.
- ‘할 수 있다’와 ‘하여야 한다’, ‘및’과 ‘또는’, 원칙과 예외를 구분한다.
- 법률과 시행령의 근거를 분리해 기록한다.
- 조문 번호와 강의 번호를 동일시하지 않는다. 실제 목차의 TB-001~TB-025를 기준으로 한다.
- SVG의 title/desc와 각 강의 README에 읽을 수 있는 내용을 제공한다.
- 일부 긴 조건 설명은 그림에서 핵심을 표시하고 강의 README에 전체 주석을 남긴다. `display_notes`는 그림에 표시할 주석, `notes`는 전체 주석이다.

## 화면 표시

SVG·PNG·WebP는 같은 내용을 담는다. SVG는 원본 편집과 확대에, PNG는 고정된 글자 모양 확인에, WebP는 웹 표시용으로 사용한다. 작은 화면에서는 전체 이미지를 무조건 축소하기보다 원본 확대를 제공한다. 갤러리는 작은 화면에서 한 열로 배치하며, 이미지를 누르면 원본을 연다.

SVG 글자는 편집 가능하도록 텍스트로 유지한다. Noto Sans CJK KR이 없는 환경에서 글꼴이 바뀔 수 있으므로 고정 표시가 필요할 때는 PNG 또는 WebP를 사용한다.

## 재생성

저장소 루트에서 다음 순서로 실행한다. Python의 Pillow, Node.js의 sharp, Noto Sans CJK KR 글꼴이 필요하다.

```bash
python3 scripts/notion-diagrams-v1/build.py
node scripts/notion-diagrams-v1/render.cjs
python3 scripts/notion-diagrams-v1/package.py
```

수정할 데이터는 [content.json](content.json)이다. 새 버전은 기존 사용 중인 파일을 덮어쓰기 전에 내용과 이미지의 일치, 여백, 예외 표시, 파일 해시를 확인한다.

이 도식 묶음에는 강의 영상의 삽입 시각이나 재생 동작을 정하는 정보가 포함되지 않는다.
