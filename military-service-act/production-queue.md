## 시간별 실행 규칙

예약 주기는 외부에서 **매시간** 설정한다. 이 파일의 생성은 예약 생성·작업 실행·추가 공개를 뜻하지 않는다. 조정자 한 명만 공용 큐와 공개 결과를 수정하며, worker 수는 `maximum_available`을 실제 런타임 가용 슬롯으로 제한한다. 조정자와 다른 작업의 점유 슬롯을 제외하고 가능한 작업을 병렬 배정한다. 큐 크기에 임의 상한을 두지 않는다.

중첩 호출은 활성 임대와 잠금을 확인한다. 작업자는 격리된 결과와 검토 근거만 돌려주고, 조정자는 ID 예약·상태 변경·통합·원자적 공개를 맡는다. 만료된 임대는 같은 작업의 마지막 체크포인트에서 복구한다.

## 작업 한 건의 처리

1. **공식 원문을 먼저 대조한다.** 작업의 URL·판본·본문 SHA-256을 확인하고, 기존 [내용](editorial-content.json), [전체 manifest](diagrams-manifest.json), 연결 강의의 `lesson-NNN/diagrams/manifest.json`에서 실제 내용까지 비교한다. 출처 키에 없다는 이유만으로 결함이나 제작 필요를 선언하지 않는다. 본문 해시는 초기 추출 텍스트의 식별값이므로 HTML 응답 해시와 혼동하지 않고, 추출 공백 차이를 개정으로 오인하지 않는다.
2. 별도 학습 가치가 없거나 서식 지정에 그치면 이유를 남겨 `no_diagram_needed`; 기존 도식이 적합하면 ID·판본·강의 연결 근거를 남겨 `reuse_verified`로 닫는다. 여러 후보가 같은 주제이면 하나의 생산 작업과 공통 결과로 연결한다.
3. 유용한 추가 주제만 한 장 한 주제로 만든다. 주체·조건·기간·기산점·예외·의무/재량·및/또는·벌칙 하한을 보존한다. 승인된 **흑백 editorial-monochrome-v1, 1600×1120, 편집 가능한 SVG + 무손실 WebP**를 사용한다. 굵은 제목·가는 구분선·손그림 타원/괄호와 현행 한글 조판을 유지한다.
4. [SVG 빌더](tools/build_editorial.py)와 [WebP 렌더러](tools/render_editorial.cjs)를 격리된 staging에서 사용한다. 필요한 Noto Sans CJK regular/bold 폰트를 확인한다. 현재 ID와 경로를 유지하고 **강의별 최대 D번호 뒤에만** 조정자가 예약한 ID를 추가한다. 불필요하게 기존 내용을 재정렬하거나 재작성하지 않는다. 공식 원문 대조로 확정된 오류는 같은 ID에서 이전 파일 해시와 수정 근거를 기록해 교정할 수 있다.
5. 법률 의미와 렌더링을 검수한다. 글자 잘림·한글·축소 가독성·픽셀 크기·무손실 형식·파일 크기·SHA-256·조문 출처를 확인한다. 실패는 구체적 근거와 함께 `blocked`로 두며 완료 수에 포함하지 않는다. 동일 오류를 매시간 무한 재시도하지 않는다.
6. 조정자가 새 SVG/WebP, 내용, 전체/강의별 manifest, 관련 README·검색 갤러리·레이아웃 검사 기록, [공식 출처 기록](editorial-sources.json), [내용·레이아웃 감사](editorial-audit.json), 해시·크기·완료 근거를 **하나의 원자적 공개 변경**으로 통합한다. 최신 공개 commit과 충돌 여부를 확인한다. 공개 commit과 실제 산출물 ID를 남긴 뒤 `published`로 닫는다. 비공개 스냅샷·강의 내레이션·계정 정보는 업로드하지 않는다.

## 근거·재개·종료

각 상태 전이는 `production-evidence/{job_id}/{sequence}-{evidence_sha256}.json` 형태의 **새 불변 근거**로 남긴다. 직전 근거 해시, 공식 본문 해시, 비교·결정 이유, 산출물과 공개 commit을 연결한다. 이 경로는 향후 기록 규칙이며 현재 근거 파일이나 실행 완료 기록을 생성했다는 뜻이 아니다. 과거 근거와 작업 ID를 덮어쓰지 않는다.

현재 판본은 **병역법 2026-12-10, 시행령 2026-10-02, 시행규칙 2026-10-29 시행판**이다. 구체적으로 검증한 새 개정·결함 증거·사용자 요청이 있을 때만 별도 근거와 새 작업을 등록한다. 시간 경과만으로 판본을 바꾸거나 완료 작업을 다시 만들지 않는다. 모든 범위는 병역법에 한정한다.

**303건이 모두 종료되고 대기·활성·차단 작업이 0이면**, 종료 유형별 작업 수와 실제 추가 개념/이미지 수, 재사용, 기준본 유지, 공개 commit을 한 번 최종 보고하고 외부 반복 producer를 일시정지한다. 299건을 299장 완료로 집계하지 않는다. 큐가 비었다는 이유로 임의 재검수나 다른 과목 작업을 생성하지 않는다.
